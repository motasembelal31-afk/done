# تطبيق محلولة | Done App

تطبيق فوري لتوصيل المنتجات وحجز المزارع والمطاعم.
يحتوي على:
- تسعيرتين للمنتجات (توصيل عادي، توصيل فوري).
- 3 واجهات رئيسية (المستخدم، المالك/التاجر، المطور).
- تسجيل دخول فعلي عبر بريد Gmail.
- أزرار بتصميم هندسي بارز وألوان تعتمد على الأبيض، الأزرق الغامق، والبرتقالي.

## الواجهات
1. **واجهة المطور**: محمية ومخفية، تمتلك صلاحيات شاملة.
2. **واجهة المالك/التاجر**: مصغرة وتسمح بإدارة المنتجات، الأسعار، واستقبال الطلبات.
3. **واجهة المستخدم**: الواجهة الرئيسية الأكبر للطلب المباشر والتواصل عبر الواتساب.

## التقنيات المستخدمة
- HTML5, CSS3, JavaScript.
- سيتم ربط المشروع بـ Firebase للتعامل مع قاعدة البيانات وتوثيق الايميلات.
